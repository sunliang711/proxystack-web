# 账号管理与活跃会话

## 功能范围

账号安全页面提供当前账号的活跃会话、管理员与只读账号管理、两步验证及登录保护说明。管理账号与代理用户相互独立。

活跃会话列表包含来源 IP、客户端、最后活跃时间、有效到期时间与当前会话标记。账号可以注销自己的任意会话，注销当前会话需要确认。列表仅返回未超过闲置或绝对有效期的会话，管理标识与认证令牌和数据库令牌哈希相互隔离。

管理员可新增账号、修改用户名、切换管理员或只读运维角色、停用或启用账号，以及重置密码。管理操作需要验证操作者当前密码；账号修改、会话撤销与审计在同一事务内提交。最后一个启用的管理员不能被停用或降级，当前账号不能被停用。

只读运维通过后端操作白名单授权，未列入白名单的操作默认拒绝。配置写入、部署、备份下载、订阅凭据、配置明文预览及账号管理操作仅限管理员。自己的密码、两步验证及会话管理保留可用。

## 数据与部署

数据库自动迁移补充角色、停用状态和最近登录时间。现有账号默认具有管理员权限并保持启用。数据库备份及恢复保留这些字段；保留本机账号时保留其完整状态。无需增加配置项或外部依赖。

管理端升级包含数据库迁移及前端资源，可在同一变更窗口完成。订阅端无需配合升级。角色变更、停用和密码重置撤销相应会话；长连接每秒复核会话，不延长闲置有效期。

## 验证

验证覆盖新增与改名、重复及非法用户名、角色与状态切换、密码二次验证、首次改密、重置密码、会话及重置链接撤销、最后一个管理员的并发保护、只读接口权限、跨账号会话隔离、双重有效期过滤、注销当前会话的 Cookie 清理及事件流关闭。旧版数据库升级与账号恢复验证覆盖角色、停用状态和最近登录时间。

后端全量测试、关键场景的竞态检查、前端类型检查与生产构建均通过。浏览器验收覆盖新增账号、角色切换、只读账号首次改密、管理入口权限、当前会话注销确认及退出，以及 390 像素窄屏下的会话卡片、账号表格横向滚动与管理弹窗。

前端现有测试共 144 项，143 项通过；设置搜索索引校验仍报告“数据库大小告警阈值”未加入全局搜索。相关设置与测试未在本次变更中修改。
