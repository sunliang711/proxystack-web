# Stack 各用户用量明细

- 在 Stack 用量统计选择“全部用户”时展示用户明细，包含今日、本月、近 30 天的上行、下行和合计，支持排序、分页和用户详情跳转。
- 扩展既有 `GET /api/stacks/{id}/usage` 返回的 `by_user` 字段，一次查询本 Stack 的用户记录，合并同一用户的全部凭据档案，计入尚未落库增量。沿用每 10 秒刷新的机制。
- 总量继续使用入站计数；用户计数独立聚合，避免重复累计。无法映射的用户计数显示“未识别用户”，共享认证流量不一定包含在用户明细中。已删除用户保留历史，当前时间段内无记录的用户不显示。
- 影响范围：`internal/app/stack_usage.go`、相关测试、前端 API 类型及 `web/src/views/stack/UsageTab.vue`。
- 验证覆盖：多凭据档案合并、Stack 隔离、日/月及近 30 天边界、未知及已删除用户、内存增量落库前后一致、空数据与指定用户筛选。
- 无数据库迁移、配置项或第三方依赖变更。
- 发布：部署到测试机 `10.2.78.11` 后复查真实接口、筛选和详情跳转。
