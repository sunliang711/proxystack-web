# 依赖升级条件修复

- 问题：依赖页面的升级按钮始终可用；后端把版本不同直接视为有更新，可能把较旧版本当作升级。
- 修复：后端严格比较版本优先级，覆盖数字主版本、预发布标识和 Geo 数字发布标识；相同、较旧、未知版本不标记更新。前端据此禁用升级按钮，未安装时仍可安装最新版。
- 范围：`internal/deps/version.go`、`internal/app/deps.go`、`web/src/views/DepsView.vue` 及对应测试。
- 验证：版本比较表驱动测试；依赖状态接口的更新可用性测试；Go 相关包测试、前端测试及生产构建。
- 数据库、配置和依赖：无变更。
- 发布：构建 Linux amd64 二进制，部署到测试机 `10.2.78.11`，保留旧二进制用于回退。
