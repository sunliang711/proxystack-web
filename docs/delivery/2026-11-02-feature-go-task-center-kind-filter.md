# 任务中心按类型过滤

## 背景与实现

任务中心原有来源和状态筛选，本次增加任务类型筛选，并保持服务端分页与筛选总数一致。

- `GET /api/task-center` 增加 `kind` 查询参数，默认值为 `all`。
- 列表查询和总数查询按 `kind` 精确匹配，运行中总数仍统计全部任务。
- 任务中心增加可搜索的任务类型下拉框，来源切换时重置任务类型。
- 任务列固定为 260px，最近输出列使用剩余空间。
- Stack 列表顶部“刷新出口 IP”按钮改为“出口IP”。
