# 全站深色界面与布局调整

## 改动范围

按深色精致方向统一页面视觉，保留现有业务操作、接口和数据结构。

- 全站使用深蓝灰背景、分层卡片、青绿色强调色，统一文字对比度、边框、圆角、间距和焦点样式；保留浅色及跟随系统选项，并记住明确选择的主题。
- 导航统一品牌区、版本信息、分组和选中状态；手机使用覆盖式导航，关闭时不占正文宽度，切换页面后自动收起。
- 管理页左上角与登录、修改密码、重置密码页面统一复用 `favicon.svg`，移除原来的独立图标和渐变底图。
- 总览、流量明细和 Stack 用量突出关键统计；筛选器独立排列，图表和提示框适配深色主题。
- 列表统一标题、工具栏、表格留白和横向滚动，避免窄屏挤压列内容。
- 用户详情基本信息采用响应式双列布局；设置页统一折叠卡片和固定保存区；模板编辑与预览统一高度、间距及代码容器。
- Stack 所有页签共用带边框的内容面板；拓扑增加底纹，规则编辑行支持换行，日志及生成预览统一容器样式。
- 登录、修改密码、重置密码页面共用新的品牌区与表单卡片；抽屉和弹窗限制在视口内，窄屏表单标签置顶。

## 逐页复查发现与修正

本轮逐页查看了 20 个主页面在 1440px 桌面和 390px 手机视口的截图，并检查 Stack 常规页签、设置分组、认证页和入站编辑抽屉。判断标准包含对齐、留白、阅读顺序、操作区占用和长内容表现。

| 位置 | 发现的问题 | 修正 |
| --- | --- | --- |
| 设置分组 | 组件库首项样式覆盖了标题顶部间距，实际为上 0px、下 18px | 限定外层折叠标题，提高样式优先级，展开与折叠时均为上下 18px |
| 设置范围输入 | 端口池和维护时间窗在手机上换行，区间分隔符与终点脱离 | 两端输入和分隔符使用三列网格，保持同一行 |
| 卡片与用户详情 | 内容区选择器与实际 DOM 不符，手机留白和用户基本信息双列布局未生效 | 改用实际的 `.n-card-content`，复核宽窄屏 |
| 用户详情双列 | 长说明撑高同排短表单项，输入框与标签之间出现过多空白 | 表单项在网格内顶部对齐，保留各自内容高度 |
| 手机卡片标题栏 | 操作区被统一强制换行，连单个按钮或状态也占一整行 | 根据标题和操作内容的实际宽度换行 |
| 手机表单 | 标签沿用靠右布局，必填标记远离标签，且保留桌面标签高度 | 标签置顶靠左，文字与标记一起排列，移除多余最小高度 |
| 系统信息、订阅状态 | 固定表格布局叠加描述组件的跨列单元格，使正文挤到表格左半边 | 恢复自适应布局，手机标签列使用统一宽度 |
| 依赖页 | 双列详情和无最小宽度的安装记录在手机端挤成窄列 | 手机详情单列排列，安装记录在表格内横向滚动 |
| 定时任务 | 固定操作列在手机上盖住任务名称及说明，cron 可能折行 | 操作随表格滚动，cron 表达式保持一行 |
| 时间与空状态 | 浏览器语言导致 AM/PM 时间反复折行，空表格叠加了两层留白 | 统一中文 24 小时制显示，移除嵌套空状态的额外 padding |
| 模板与生成预览 | 代码内容不断撑高编辑器，使后续预览和操作难以抵达 | 限制编辑区高度，在编辑器内滚动，模板两栏保持一致高度 |
| 手工节点 | 默认展开的说明与示例占据大半个页面 | 默认折叠说明，保留随时展开入口 |
| 总览与流量明细 | 手机筛选区和统计卡片过度纵向堆叠 | 总览用户筛选与刷新并排，流量明细的上行与下行并排 |
| 入站覆盖项与监听账号 | 用户覆盖项保留 120px 桌面缩进，多个账号控件在窄屏横向挤压 | 手机取消缩进，账号控件纵向排列 |
| 手机导航与中等屏幕顶栏 | 关闭后侧栏内部链接仍可获得键盘焦点，面包屑只显示截断片段 | 关闭侧栏设置 inert，1023px 及以下面包屑显示当前页 |

宽表格和拓扑仍保留内部横向滚动，以保留完整内容。本轮使用测试机已有数据检查布局，不代替大数据量场景与全部业务流程的端到端验证。

最终版本已更新到测试机，服务状态为 active。再次加载 20 个主页面在 390px 与 1440px 下的布局，共 40 次检查，未发现页面级横向溢出或前端运行错误；补查 768px、1024px 的 Stack 顶栏，以及端口池、维护时间窗、Mihomo 账号条件表单和桌面用户详情双列。测试中没有保存配置表单，结束时还原表单草稿、设置折叠状态及浏览器视口，并返回系统设置页。

第二轮调整前的测试机二进制保留于 `/opt/proxystack-web/bin/proxystack-web.before-layout-audit-20261101`。本地构建、32 项前端测试及差异空白检查均通过。统一图标后再次构建，并在测试机检查管理页及认证页图片加载和显示正常。
