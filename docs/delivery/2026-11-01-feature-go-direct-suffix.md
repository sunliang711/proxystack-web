# Stack 直连节点后缀配置

## 背景与方案

每个 Stack 可以在「上游 → 直连上游订阅」设置直连节点后缀，默认值为 ` [DRT]`，包含一个前导空格。后缀按原样追加，保留空格；留空或旧配置未提供时使用默认值。多个外部上游继续在后缀前标注上游名。保留原订阅节点、用户授权和现有命名模板规则。

左侧菜单与对应页面标题统一改为「备份与还原」。

## 配置与存储

- Stack 文档新增可选字段 `direct_suffix`，沿用现有 Stack API 和配置导入导出，不新增接口或依赖。
- 数据库迁移 `00010_stack_direct_suffix.sql` 添加字段并为旧 Stack 设置默认值。
- 后缀不允许换行或制表符，错误定位到上游页的对应输入项。
- 前端显示默认值说明及随输入更新的命名示例。
- 保存后即可在管理端预览；发布订阅包并由订阅端导入后，Clash、Premium Clash 和 Surge 使用新名称。

## 备份清理核查

数据库备份定时任务默认每天 04:00（实例配置时区）执行，保留最近 7 份。每次生成成功后，仅清理超出保留份数的 `auto-*.db`。页面和更新接口要求保留份数至少为 1。手动迁移包及恢复前备份不参与该清理规则。

## 部署与回滚

目标为测试机 `10.2.78.11` 的管理服务；订阅端不需要新增解析能力。部署前备份管理端 binary 和数据库，重启后自动执行第 10 版迁移。需要回滚时先停止管理服务，再恢复旧 binary 和对应数据库备份。
